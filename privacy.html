隐私声明

最后更新：2026 年 8 月

概要

Pricer 是一个酒店比价工具。我们不收集、不存储任何个人身份信息。搜索条件只在你的浏览器里临时使用，结果来自第三方 API（Booking Affiliate 等）。

我们收集什么

  • 搜索条件：酒店名、入住/离店日期、人数、儿童年龄 —— 只在浏览器内存中临时使用，用于调用第三方 API
  • 点击行为：你点击"去 Booking 看"按钮时，浏览器会跳转到对应 OTA 页面 —— 由 OTA 自己的隐私政策负责

以上数据不会发送到 Pricer 自己的服务器（Pricer 暂时没有自己的服务器）。

我们不收集什么

  • 姓名 / 邮箱 / 电话等个人身份信息
  • 账号 / 密码
  • 支付信息
  • 精确位置（GPS / IP 定位）
  • 设备指纹 / 浏览器指纹

第三方服务

查询酒店时，搜索条件会发送到以下第三方 API：

  • Booking.com Affiliate Partner API：用于获取 Booking 上的酒店报价。详见 Booking 的 隐私政策
  • Agoda Partners API（计划接入）：详见 Agoda 的隐私政策

这些 API 可能记录你的 IP 地址、User-Agent 等技术信息，由各自的隐私政策约束。

Cookie

Pricer 不使用任何追踪 Cookie。不使用 Google Analytics、不使用 Facebook Pixel、不使用任何第三方分析工具。

数据保留

Pricer 没有自己的服务器，所以没有"数据保留"一说。搜索结果来自第三方 API，关闭页面后浏览器内存里的数据自动清除。

儿童隐私

Pricer 不面向 13 岁以下儿童。我们不主动收集儿童信息；但如果搜索包含儿童年龄（这是 Booking API 必需的字段），这些年龄数据也只临时传给第三方 API，不在 Pricer 端存储。

变更通知

本页内容如有更新，会在此页面顶部标注日期。
