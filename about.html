一个房间 · 多家来源 · 找到最低价

关于 Pricer

Pricer 是一个酒店比价工具。输入酒店名，就能看到这家酒店在不同 OTA（Booking、Agoda、Expedia、携程等）和酒店官网上的报价，自动高亮最低价。

为什么做这个

订酒店时，同一个房间在 Booking 上 ¥888、Agoda 上 ¥920、酒店官网 ¥850——手动对比至少打开 5 个标签页，而且要选相同的入住/离店日期、相同的人数条件。对比一次下来要十几分钟。

Pricer 把这个流程压缩到 输入酒店名 + 选日期 → 看结果，几秒完成。

使用场景

  • 个人出行：订自己的酒店，对比同房型不同渠道的报价
  • 商务差旅：替公司订房，挑找能开正规发票的渠道
  • 家庭旅行：多人多儿童，需要看具体房型适合多少人

数据来源

目前接入：

  • Booking.com 通过 Booking Affiliate Partner Program（已申请中）
  • Agoda 通过 Agoda Partners API（计划接入）
  • Expedia 通过 EAN Affiliate Network（可选）

展示中标注"示例数据"的水印表示当前是 mock 数据，接入真实 API 后会替换。

国内 OTA

携程、美团、飞猪、去哪儿暂无公开搜索 API。这些平台的反爬机制严格、价格通常客户端渲染、且 ToS 不允许自动化抓取。短期内不接入这些渠道。

技术栈

纯 HTML + CSS + Vanilla JavaScript，无构建工具、无 npm、无框架。一个文件就能跑，方便审阅代码逻辑，也方便部署到 GitHub Pages。

隐私

Pricer 不收集、不存储任何个人身份信息。搜索条件只在浏览器本地临时使用，结果来自第三方 API。详见 隐私声明。
